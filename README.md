AI Image Generator Website

A modern, responsive AI Image Generator web application built with HTML, CSS, JavaScript, and Express.js, leveraging the ClipDrop API to generate images from text prompts. Users can input a description, generate images in real-time, and download the results directly from the interface.
Features

Clean and intuitive frontend design using HTML, CSS, and JavaScript.

Responsive layout optimized for desktop and mobile devices.

Express.js backend handling API requests securely.

ClipDrop API integration for generating high-quality AI images from text prompts.

Download functionality to save generated images.

Error handling for smooth user experience.

Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

API: ClipDrop Image Generation API

Installation

Clone the repository:

git clone <your-repo-link>


Install dependencies:

npm install


Create a .env file and add your ClipDrop API key:

CLIPDROP_API_KEY=your_api_key_here


Run the server:

node server.js


Open http://localhost:3000 in your browser.

Usage

Enter a text prompt in the input box.

Click "Generate" to create the AI image.

Download the generated image with the Download button.
