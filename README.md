# AI Image Generator Website

A modern, responsive **AI Image Generator** web application built with **HTML, CSS, JavaScript, and Express.js**, using the **ClipDrop API** to generate images from text prompts. Users can generate images in real-time and download them directly from the interface.  

## Features
- Clean and intuitive **frontend** design.
- Fully **responsive layout** for desktop and mobile.
- **Express.js backend** to handle API requests.
- Integration with **ClipDrop API** for AI-powered image generation.
- **Download functionality** for generated images.
- Smooth error handling for a seamless user experience.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **API:** ClipDrop Image Generation API
